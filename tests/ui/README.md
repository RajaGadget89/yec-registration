# UI Tests

This directory contains UI-related test files and HTML snapshots.

## Files

- `test-http___localhost_8080_.html` - Main page HTML snapshot
- `test-http___localhost_8080_admin_login.html` - Admin login page HTML snapshot
- `test-http___localhost_8080_admin_login_next__2Fadmin.html` - Admin login redirect HTML snapshot

## Purpose

These HTML files contain snapshots of UI pages captured during testing to analyze hydration issues and UI behavior.

## Usage

These files are used for debugging UI rendering issues and comparing expected vs actual HTML output.
